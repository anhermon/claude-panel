One call became a bounded loop. The sleep is full jitter: a random time up to a ceiling that doubles each attempt. Only 503 is retried.

Findings

Must fix

The file handle is reopened on every attempt and never closed.

Should

Nit

Reveal one at a time, worst first. The handle leak is the only blocker: under retries it multiplies.
